# Личные банковские источники

Дата2026-10-16. Формат: личное приложение, Android APK без публикации. Страна, реальные банки, package names, валюты счетов и обезличенные уведомления владельца пока неизвестны. Не выбирать за пользователя банк или финансового провайдера и не утверждать доступ к счетам по одному каталогу API.

Базовая версия технически принята по отчету STAGE-05-REPORT.md; device runtime не выполнялся по поручению без эмуляторов. Это не блокирует независимую реализацию source pipeline и локального прототипа.

Реализован S1-03: локальный parser с явным пакетом приложения/счетом/валютой/направлением и шаблоном владельца. Грамматика содержит {amount}, опциональные {currency}, {merchant}, {card}; литералы экранируются, весь текст должен совпасть. Это настраиваемый механизм, а не подтвержденная поддержка конкретного банка. Автоматический режим выключен по умолчанию и требует успешной локальной проверки текущего шаблона и отдельного подтверждения владельца. Только новые однозначные события с устойчивым notification slot могут поставить preliminary; повторы/неопределённость/совпадения остаются для сверки. Окончательное списание и отмена требуют явного решения. Повтор определяется identity уведомления, а не совпадением суммы/даты.

Реальные образцы должны исключать OTP, пароли, полный PAN и реквизиты. Синтетические примеры в tests/fixtures/notifications не являются банковскими доказательствами. OFX/SMS не входят в обязательную область; API provider откладывается до выбора банков и разрешенного способа доступа.

Общий parser/listener/inbox/worker и web/native review реализованы и проверены синтетически (STAGE-06-REPORT.md). Недостающая внешняя зависимость — реальные package names/образцы/выписки и разрешённый API доступ; публикация и аккаунты магазинов не требуются.
