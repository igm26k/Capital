# Источники банковских данных: предварительная матрица

Дата проверки документации:2026-10-16. Целевые страна/банки не определены, поэтому покрытие конкретного счета, цены и возможность личного доступа не подтверждены. Внешние аккаунты не создавались, авторизации не выполнялись.

| Источник | Документально подтвержденный механизм | Что остается неизвестным |
|---|---|---|
| GoCardless Bank Account Data | Requisitions, accounts, transactions/balances и rate-limit responses описаны в [официальных endpoints](https://docs.gocardless.com/docs/bank-account-data/endpoints) | Подключение нового личного клиента, нужные банки, глубина истории, доступные поля, стоимость и индивидуальные лимиты |
| Tink | [Официальная документация](https://docs.tink.com/) описывает Console и credentials; [API reference](https://docs.tink.com/api/statistics) использует OAuth scopes | Конкретный банк/счет владельца, условия личного доступа, договор, стоимость и период повторной авторизации |
| Plaid | [Quickstart](https://plaid.com/docs/quickstart/) разделяет client/server и credentials; [Sandbox](https://plaid.com/docs/sandbox/) является тестовой средой | Нужная страна и продукт, доступ к реальному банку, production approval, стоимость и ограничения OAuth |
| Android уведомления | [NotificationListenerService](https://developer.android.com/reference/android/service/notification/NotificationListenerService) предоставляет callback после явного включения системного доступа | Реальные package names/форматы, доступность скрытого текста, доставка на устройстве, полнота истории |
| CSV | Собственный UTF-8 mapping/preview/apply и idempotent import уже реализованы | Примеры конкретных банков/колонки/кодировки и совместимость этих файлов |

Решение для текущей реализации: CSV сохраняется рабочим резервным путем; добавить локальный настраиваемый parser/opt-in inbox без утверждений о поддержке конкретного банка. API адаптер не выбирать случайным образом без целевых банков и разрешенного доступа. Документация провайдера является уровнем «документация», а не «sandbox» или «реальный счет». Наличие endpoint не доказывает доступность регистрации нового клиента. После определения банка эту таблицу дополнить реальной строкой банк/страна/счет/источник/дата/уровень доказательства.
