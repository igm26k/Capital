Статус: in_progress
Область: backend/internal/banking/, ledger/source_events.go, HTTP source routes, contracts, migration0008

Первый пакет: pure decision engine различает namespace подключения/внешние ID/explicit pending reference; слабое совпадение суммы/времени/продавца ведет только на review, отмены без исходной связи не создают запись. Linked proposal сохраняет ID и ожидаемую версию; алгоритм сам не меняет финансовые данные или пользовательскую классификацию.

Следующий пакет: durable structured source-event intake с частным доступом владельца, session/generation/idempotency guards, новым source identity без объединения одинаковых покупок. Прием события пока только review, без финансового эффекта. После приемки intake реализовать explicit decision/linkage и pending→posted через финансовый CommandRunner; не использовать posted ручную операцию вместо предварительной.
