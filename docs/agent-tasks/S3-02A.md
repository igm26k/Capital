Сценарии приемки: Подготовить DB constraints DR-F01/F05 и межпространственные FK DR-A02; не выдавать их за HTTP-проверку.

Реальная PostgreSQL: первое/повторное применение и 19 негативных CHECK/FK/UNIQUE сценариев — PASS; currency seed, сохранение receipt при очистке группы/смене поколения — PASS. Локальная БД: применены 3 миграции, повтор count=0, история версий и readiness API проверены. Финансовые межстрочные сервисные инварианты и HTTP-доступ еще не реализованы.
