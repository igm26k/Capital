# S6-06: подготовка личной установки
Статус: done (техническая подготовка; фактическая установка на устройстве не выполнена)
Исполнитель: координатор
Область пересмотрена владельцем2026-10-16: приложение только для личного использования. Публикация в Google Play, других магазинах и публичном вебе исключена. Аккаунт площадки, публичный пилот, открытая регистрация, SMTP и публичный production домен не являются блокерами реализации.

Готово: Android debug APK и release APK/AAB, проверка подписи disposable ключом, инструкции учета/CSV/восстановления, личной установки и эксплуатации; backend/web/Android технические gates перечислены в STAGE-05-REPORT.md. Существующий release APK unsigned; тест подписи не заменяет стабильную подпись личной устанавливаемой версии. Для пробной установки доступен debug APK; для постоянного использования нужен защищенный стабильный ключ, сохраняемый между обновлениями.

Фактическая установка на телефоне владельца, устройство/background/offline runtime и настройка его постоянного сервера не заявляются выполненными. Эмуляторы исключены поручением пользователя. Эти ограничения не требуют публикации и не препятствуют дальнейшей реализации доступных банковских задач после технической приемки базовой версии. Требующие реальных банков/образцов проверки остаются отдельными внешними зависимостями.

Инструкции: docs/RELEASE_MATERIALS.md, ops/runbooks/release.md. Ранее записанные требования публичного выпуска отменены текущим решением; исторические результаты тестов не изменены.
