# S4-02: Android уведомления и доставка структурированных предложений
Статус: in_progress (ручной review transport принят; многопрофильная настройка и автоматический режим далее)

Реализованы opt-in listener, bounded template parser, local noBackup inbox с replay/conflict receipts, отправка typed candidate и серверный разбор прямо в Android. Source namespace/record ID стабильны между логинами и сменой generation; timezone наблюдения UTC, raw notification/key/token не передаются. Отправка и финансовые решения сохраняются до HTTP в session-bound auxiliary store; retry сохраняет key/body/generation, unknown не перепривязывается к новой сессии. Shared financial outbox/protocol не расширялся: server worker публикует обычные account/transaction changes. Реализованы create_pending/link/dismiss, optimistic confirm/cancel, проверка связанной операции и paging выбора существующей. После обработки подтягивается обычный финансовый mirror. Source auxiliary files удаляются при удалении профиля.
