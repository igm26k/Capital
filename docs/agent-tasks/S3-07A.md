Результат: Первый вертикальный путь принят на настоящих Go/PostgreSQL/Chrome. Новый Go API handler/service/pool восстановил сессию, остаток и исходный JSON receipt. Чужой GET/assignment отклоняются 404; CSRF перед replay 403 и generation 409 подтверждены настоящим HTTP/browser. DR-F02/F03 overflow/split ранее приняты в S3-02B и здесь не объявляются новым покрытием.
