# S4-05: выбранный банковский API provider
Статус: blocked

Внешняя зависимость: страна и реальные банки владельца, доступный им разрешённый API provider, предусмотренная авторизация/credentials/sandbox и условия доступа. Эти входы отсутствуют. Публикация, магазин и публичный пилот не требуются.

Generic reconciliation, источники/receipts/jobs, версии и private controls готовы. Provider-specific adapter не реализуется под вымышленный банк и не объявляется проверенным по mock. Уведомления и CSV приняты отдельно; это не блокировка независимой реализации.

После появления конкретного разрешённого доступа: проверить официальные условия, реализовать scoped adapter/token storage/revoke/refresh/statuses, использовать stable external/pending IDs, затем сравнить с контрольной выпиской. Текущие доказательства и границы — STAGE-06-REPORT.md и docs/research/bank-sources.md.
