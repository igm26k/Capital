# CSV-01: CSV-импорт, идентичность источников и восстановление заданий
Статус: done
Исполнитель: координатор, последовательно
Зависимости: финансовое ядро; бюджеты/отчеты реализуются и проверяются в том же цикле
Входы: docs/implementation/08_CSV_IMPORT_PLAN.md, contracts/openapi.future.json
Разрешенные файлы: backend/, web/, android/, contracts/, scripts/, compose.test.yaml, Makefile, docs/
Решения: UTF-8; до10MiB/1000 строк; предпросмотр24h; raw CSV после разбора не хранится. Деньги и даты разбираются точно; сумма+дата не доказывают дубль. Идентичность: hash содержимого+mapping+номер строки. Две одинаковые строки имеют разные идентификаторы; повтор файла сохраняет исходные ссылки. Совпадения с ручными записями требуют отдельного решения. Worker применяет каждую строку финансовой командой с постоянным ключом. Состояние задания/источника фиксируется атомарно с финансовыми движениями и квитанцией. Worker авторизуется по сохраненной сервером issuing session и проверяет ее отзыв/истечение/права; токены в заданиях не хранятся. Ошибки и повтор после явного подтверждения не переиздают уже примененные строки.
Проверки: parser unit, PostgreSQL/TLS jobs/retries/access, Chrome; Android build/unit/lint без emulator.
