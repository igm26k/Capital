# S6-04: сборки Android и веб
Статус: review
Исполнитель: координатор, последовательно
Область: android/, web/, scripts/check-android-release-trust.py
Задача: debug/release/test APK, unit и lint, типы и production bundle веба, Chrome regression. Проверить system-only release CA и запрет cleartext; отсутствие банковских разрешений.
Результаты: debug/release/test APK,53unit/lint, system-only compiled trust PASS; web build/types и21Chrome E2E PASS. Доказательства в STAGE-05-REPORT.md. Release APK не подписан ключом владельца. Device runtime не запускался по прямому поручению пользователя; несколько браузеров и физические устройства остаются внешней приемкой перед публикацией.

Расширение2026-10-16: защищенная необязательная signing configuration для APK/AAB, ops/android-release.sh и disposable-key self-test scripts/check-android-signing.sh. Ключ владельца не генерируется и не заменяется тестовым. Проверяются подписи, bundle и compiled system trust; после self-test возвращаются unsigned кандидаты. Итог текущего прогона — STAGE-05-REPORT.md.

Актуализация области2026-10-16: только личное использование, без публикации и внешнего пилота. Требования магазина/публичной инфраструктуры выше больше не являются блокерами. Технические результаты и непроведенные device проверки сохраняются; S6-06 теперь означает подготовку личной установки.
