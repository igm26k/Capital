# S3-06A: Первый сквозной сценарий в вебе

Статус: done
Исполнитель: Веб
Зависимости: S3-01B, S3-01C, S3-02B, S3-03A, S3-04A
Входы: docs/decisions/001–007, contracts/openapi.json (0.2.0), contracts/fixtures/design-review-cases.json
Разрешенные файлы: web/src/api/, web/src/shared/, web/src/features/auth/, web/src/features/accounts/, web/src/features/transactions/ (basic), web/tests/e2e/basic.spec.ts; собственная карточка и отчет этапа. Общие миграции/контракты — только через назначенного координатора.
Задача: Register/login local/test, workspace generation, EUR opening 100000, expense 1234, итог 98766 после перезагрузки; cookie/CSRF/same-key retry, честные offline/error/conflict состояния.
Критерии приемки: наблюдаемое поведение задачи, успешные подходящие проверки, отсутствие подмены PostgreSQL/браузера заглушкой; not_run обозначается явно.
Проверки: make web-check; make e2e (basic) с реальным API/БД
Сценарии приемки: Начать DR-A10 (текстовое отображение); сквозная проверка чужого счета, повторного расхода и generation.
Внешние зависимости: Node/браузер/API/БД; mocked API не закрывает эту задачу.
Результат: Реальный React поток cookie register/login/session/logout, счет EUR и posted expense/income с одной частью, текущие остатки и последние 100 операций. BigInt minor units без float; React text rendering. Одна неподтвержденная команда (key/body/generation) сохраняется в sessionStorage текущей вкладки и повторяется после reload; новые записи блокируются до подтверждения. Generation conflict требует обновления.

Проверки: make web-check и make e2e — PASS (Chrome 154.0.8037.57, Playwright 1.63.0, Node 24.21.0, настоящий Docker API/PostgreSQL). В браузере 100000 − 1234 = 98766 после reload; потеря настоящего ответа после commit и same-key retry после reload дают одну expense. Secure/HttpOnly cookie, отсутствие bearer token, session/login/logout, чужой account 404, stale generation 409, CSRF 403, offline block, текстовое примечание DR-A10 — PASS.

Границы: полный outbox/pull/snapshot, пагинация UI, классификация/правка/advanced операции и автоматическая сверка expired receipt еще не реализованы. API/web container restart — следующий S3-07A; production TLS not_run. Регистрация включается только отдельным test overlay; local остается false. Подробности — STAGE-01-REPORT.md и web/README.md.
