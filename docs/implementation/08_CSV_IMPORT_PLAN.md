# Этап 4. CSV-импорт и экспорт

## Цель и зависимости

Добавить файловый импорт и экспорт после [приложений](07_APPLICATIONS_PLAN.md) и [бюджетов и отчетов](05_BUDGETS_REPORTS_PLAN.md). Банковские доступы и исследования не требуются: использовать описанный формат CSV и синтетические примеры.

Работать по [общему процессу](00_AI_AGENT_WORKFLOW.md).

## Пакеты задач

| ID | Результат | Зависимости |
|---|---|---|
| S4-01 | Общая модель источника, worker, повторы и идемпотентность импорта | Финансовое ядро |
| S4-03 | Загрузка CSV, выбор счета, кодировки, колонок, предпросмотр и подтверждение с отчетом | S4-01 |
| CSV-01 | Дедупликация CSV, неоднозначные совпадения и сохранение пользовательских правок | S4-03 |
| CSV-02 | Экспорт CSV с проверкой доступа и приемка импорта | CSV-01 |

Банковские части S4-04, уведомления S4-02 и API S4-05 выполняются только на финальном этапе. OFX и SMS не входят в этот этап.

## Проверки и критерии завершения

- Повторная загрузка CSV и повтор задания после сбоя не создают дубли.
- Две одинаковые реальные покупки остаются отдельными операциями; сумма и дата сами по себе не доказывают дубль.
- Предпросмотр показывает даты, суммы, валюты, ошибки и возможные совпадения до подтверждения.
- Отчет содержит созданные, сопоставленные и отклоненные строки; категории и заметки сохраняются.
- Импорт пересчитывает остатки, бюджеты и отчеты корректно; чужие файлы и результаты недоступны.
- Экспорт сохраняет точность сумм, кодировку и данные для повторного импорта.
