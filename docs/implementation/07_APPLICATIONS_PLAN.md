# Этап 2. Приложения

## Цель и зависимости

Реализовать Android-приложение после приемки [сервера и веба](03_PRODUCT_FOUNDATION_PLAN.md). Использовать готовые API и финансовую модель. Банковские уведомления, SMS и подключения отложены до финального этапа.

Работать по [общему процессу](00_AI_AGENT_WORKFLOW.md). Текущий объем — Android; другие приложения требуют отдельного определения платформ и объема.

## Пакеты задач

| ID | Результат | Зависимости |
|---|---|---|
| APP-01 | Kotlin, Jetpack Compose, Room, WorkManager, окружение сборки | Сервер и веб приняты |
| APP-02 | Регистрация, сессии, Keystore, счета, операции, категории и фильтры | APP-01 |
| S3-05 | Локальные данные, атомарный outbox, версии, курсор, удаления, повторы и конфликты | APP-02, S3-04 |
| APP-03 | Сквозная приемка Android → сервер → веб, отчет | APP-02, S3-05 |

## Проверки и критерии завершения

- Проверить сборку и работу на устройстве или эмуляторе.
- Счет и операция из Android появляются в вебе с точными суммами.
- Офлайн-создание, редактирование и удаление доходят до сервера после восстановления связи.
- Перезапуск с outbox, повторная отправка и временные ошибки не теряют изменения и не создают дубли.
- Конфликты двух клиентов показываются явно; устаревший курсор восстанавливается без потери локальных действий.
- Секреты защищены, доступ к чужим данным отклоняется, сессии устройств отзываются.
