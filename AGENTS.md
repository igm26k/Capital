# Android

- При каждом изменении Android-приложения приводите интерфейс в соответствие с мобильной веб-версией Capital, сохраняя нативные черновики, офлайн-очередь и точность денежных сумм.
- Каждая успешная сборка APK должна обновлять файл `android_latest.apk` в корне репозитория. Задачи `assembleDebug` и подписанная `assembleRelease` делают это автоматически. Неподписанный release не публикуется.
- Перед завершением Android-задачи соберите подписанный release существующим ключом через `python3 ops/personal_signing.py --sdk /opt/accounting-sdk --verify-all`, проверьте подпись и включите `android_latest.apk` в коммит и push вместе с изменениями. Итоговый APK должен быть release, пригодный для обновления установленного приложения.
- Ключи, пароли и приватные журналы сборки остаются вне Git. Не заменяйте существующий ключ подписи.
- Эмуляторы не запускать по поручению владельца. Явно указывайте, если проверка на устройстве не проводилась.
- Каждый законченный шаг коммитьте и отправляйте в удаленный репозиторий без дополнительных вопросов.
